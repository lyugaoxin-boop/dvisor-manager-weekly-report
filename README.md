# 面向导师或领导的周报助手

`dvisor-manager-weekly-report` 是一个面向学生、科研人员和职场人士的 Codex Skill。它学习导师或领导的偏好和参考模板，根据本周研究或工作材料生成可核验、可编辑的周报。

> 当前版本用于本地测试和调优，尚未发布到 GitHub。

> **适用范围声明：** 本 Skill 主要针对文本类周报，当前调优重点是正文内容、语言风格和文档排版，尚未针对 PPT/PPTX 形式进行专项调优。如需生成 PPT/PPTX，可调用 `$ppt-master`，但生成后的版式和展示效果仍需另行检查与调整。

## 核心能力

- 从偏好描述、导师/领导模板、师兄师姐/同事模板中学习风格。
- 用户未说明参考模板来源时，全部默认视为导师/领导模板；用户之后明确说明的来源始终覆盖该默认分类。
- 按需进行一问一答式澄清，并解释每个问题的原因。
- 在完整生成前展示风格示例，等待用户明确确认。
- 支持论文、实验、图片、表格、项目记录、业务指标和风险等材料。
- 每篇论文调研默认给出必要公式、实验设置（含数据集介绍）和实验结果：解释关键公式与符号，说明数据来源、规模、划分及关键对比条件，并列出具体指标和结果。仿真或案例研究介绍实际测试系统；论文没有相应内容时不编造，重要缺口在预览前按需澄清。论文中的结果与用户自己的实验明确区分。
- 按最小有意义的内容单元匹配篇幅：每篇论文、每组实验结论、每项代码/项目结论分别参照模板中的同类单元；单元越多，章节总篇幅相应增加，而不是机械套用模板章节或整篇周报的固定长度。
- 分别学习文档标题及一级、二级、三级等各级标题的字号、字体、加粗、编号、缩进、间距和分页行为，避免把不同层级压成同一种格式。
- 从多个正文样本中学习段落行距类型及数值、段前段后间距，并在模板稳定区分时分别复现普通正文、列表正文和表格内正文的段落规则。
- 把语言风格作为独立重点学习项，包括句子长短、信息密度、先结论还是先过程、用词、语气、技术细节密度以及进展、结果、风险和下一步的表达方式。
- 默认把读者视为没有相关背景但理解力强的人，用简单、直接、自然的语言说清核心观点、证据和逻辑；模板语言风格只在这一基础上调整语气、详略和组织方式。
- 不照搬模板中的晦涩行业术语、内部黑话、管理口号或生硬翻译腔。必须保留的专业名词在首次出现时用日常语言解释其实际含义。
- 资料检索、结构设计和逻辑核对保持专业严谨，但周报不展示构思过程，只呈现整理后的结论、证据链和必要解释。
- 证据不足和不允许使用的更强结论保留在内部证据记录中；周报只写当前有依据的结果，不写“缺少哪些设置，因此不能判断或不能声称什么”这类审计式说明。
- 图题和表题优先严格沿用模板样式；模板没有可参考样式时，默认比正文小一个常规字号级别。
- 公式字号优先沿用已确认模板或用户要求；两者都没有规定时，默认与正文字号一致。
- 论文默认标注为：`英文论文题目（期刊名称；年份；最新新锐分区；影响因子；通讯作者；国家单位）`。六项信息按此顺序放在同一对括号中，以分号分隔，不另起段落重复列出；年份指论文发表年份，分区版本与JIF年份各自标在对应字段内，国家单位写成“国家—单位”。英文周报仍按原规则使用JCR分区，字段顺序不变；不翻译论文题名、不显示 DOI。
- 默认保留全部非重复的图片和结果表，并配标题和分析。
- 发现表格截图时先询问是否还原为可编辑表格，并逐单元格核对。
- 已提供原生可编辑表格，或截图已经还原为可编辑表格时，周报不再重复放表格截图，除非用户明确要求两者都保留。
- 周报只分析图表数据和结论，不写“将截图还原为可编辑表格”等文档制作说明。
- 图表横纵轴文字与正文语种不一致时，保留原图并生成同正文语种的轴文字翻译版。
- 内部建立证据记录，防止数字错误、结论夸大和状态误报。
- 只学习模板中的结构和样式，不复用“汇报人、答辩人、姓名、学号、项目”等具体内容值；本次未提供汇报人、答辩人等人员身份时默认填写 `xxx`。
- 主要面向 DOCX、PDF、Markdown 等文本类周报；PPT/PPTX 可调用 `$ppt-master` 生成，但尚未进行专项调优。

## 调用

```text
$dvisor-manager-weekly-report
```

示例：

```text
$dvisor-manager-weekly-report

汇报对象：课题组导师
导师偏好：先说结论，重视实验对比和失败原因，不喜欢大段背景介绍。
导师模板：templates/advisor-template.docx
本周材料：weekly-input/2026-week-36/

请先按需询问你无法确定的关键信息。确认目标后给出风格示例，得到我的明确确认后再生成完整周报。
```

## 风格依据优先级

```text
本次周报临时要求
> 用户描述的导师/领导偏好
> 导师/领导模板
> 师兄师姐/同事模板
```

三种长期风格依据至少提供一种。只有文字偏好而没有文件模板时，Skill 会询问最终输出格式。

## 默认交付

- 周报成品：始终交付。
- 风格画像：首次建立或更新时交付。
- 证据记录：内部使用，用户明确要求时才交付。
