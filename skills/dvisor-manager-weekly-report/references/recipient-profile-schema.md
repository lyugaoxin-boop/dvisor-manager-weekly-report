# Recipient Profile Schema

Use this schema to establish or update a reusable advisor or manager profile. The profile guides content priority, evidence depth, and decision framing. It does not diagnose personality and does not replace the separate report style profile.

The profile is user-facing confirmation material stored separately from the weekly report. Never insert this schema, a completed profile, confidence notes, source records, or the recipient-fit map into the recipient-facing report.

Record only information supported by explicit user statements, supplied recipient feedback, or recipient templates. Mark every inference, its source, and its confidence. Ask for confirmation before treating an inference as a reusable rule.
